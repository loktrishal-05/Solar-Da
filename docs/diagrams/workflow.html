One farm shift from trigger to audit

Event-driven, never a blind timer. Each step writes a trace entry you can replay from any checkpoint.
1 · SENSE AND UNDERSTAND
1TriggerThreshold crossed, quality fault, model forecast, anomaly, new leaf photo, rain ahead, manual Check now, or a scheduled fallback
2IngestReplay layer emits readings tagged with their source; faults injected for tests; a stuck or drifting probe is flagged, not trusted
3AssessSensor models: 30 min and 2 h forecasts with bands, anomaly score, soil-water outlook; twin ET0 and root-zone deficit
4Specialists in parallel · the LLM proposesIrrigation · Fertigation · Climate · Disease. Each returns proposals with rationale, evidence ids, expected effect and confidence. Nothing here can act.
2 · DECIDE
5ArbiterMerges conflicting proposals, picks one per zone, cites the twin run ids behind the choice (hold / irrigate now / irrigate tonight)
6Safety gate · TypeScript engine13 original interlocks plus agent rules: dose per hour, tank limits, sensor trust, tier. Returns ALLOW, NEEDS_HUMAN or VETO with a reason. The model cannot override it.
7Human approvalL1 propose: everything waits in the inbox. Pesticide dose or spray rate always escalates to an expert. E-STOP freezes dispatch.
8DispatchIdempotency-Key per action, so a retry can never double-dose
3 · PROVE IT
9VerifyRe-reads sensors after dispatch; a missed effect raises a new trigger
10AuditAppend-only, SHA-256 hash-chained; every checkpoint replayable via /runs/{id}/history
11NotifyAlerts go to the SMS outbox (labelled SIMULATED) and optionally to a real phone via a free Telegram bot, deduplicated per 10 minutes
Example veto: ph_excursion at 60x. The agent keeps proposing pH-down; the gate returns MAX_DOSE_PER_HOUR and the dose never leaves the building.
Example refusal: blurry leaf photo → retake; clear photo → calibrated diagnosis, treatment proposal waits for a human, re-scan date set.
Data honesty: every reading and chart shows its source tag. Replayed data is never presented as live.
